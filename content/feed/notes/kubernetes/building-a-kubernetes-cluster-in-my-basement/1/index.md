## Summary

I needed a new project. So, I'm considering building a Kubernetes cluster in my
basement using mini desktop PCs. This has been done several times before. But,
from what I've read learning and understanding Kubernetes can be best described
as a learning cliff. But, I think this will be a good next step to expand my
skillsets.

In order to move forward with this project. Some other infrastrucutre will need
to be built as well. So I intend to build a three node Proxmox cluster for
hosting infrastructure to support the Kubernetes cluster beforehand or during. I
will have that as part of another series.

In this series I'm going to design, plan, and deploy a kubernetes cluster.
Providing notes on different application deployments accompanied with notes on
how Kubernetes works in other entries.
