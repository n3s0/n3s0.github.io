## Summary

For these notes I will be putting togeter and deploying my own Vaultwarden
server. Valtwarden is a Bitwarden alternative implementation written in Rust
that is compatible with the official Bitwarden clients.

I've wanted a self-hosted password management server for a while. But, haven't
taken the time to build one just yet. So, perhaps now is the time to kick the
tires on something like Vaultwarden.
